# 符計算クイズ 作成スキル

符計算の練習問題を、下記フォーマットで**問題＋想定解**として作成する。
符・飜・点数の算出ロジックそのものは [[fu-calculation]] スキルに従う（このスキルは
「妥当な問題を作る」ことに責任を持つ）。

## 出題フォーマット

```
ドラ <牌>　<自風>家　リーチ有り／リーチ無し
<手牌（門前部分）>　<鳴き情報（あれば）>
ツモ／ロン <和了牌>
```

例:
```
ドラ 4p 南家 リーチ有り
23445m556677p西西
ロン 6m
```

### 牌の表記
- 数牌: 萬子 `m` / 筒子 `p` / 索子 `s`。同種はまとめて書く（例 `23445m`）。
- 字牌: 風牌 `東 南 西 北`、三元牌 `白 發 中`。
- 鳴き: 手牌の後にスペースを空けて記す。
  - `ポン 中中中`（明刻）
  - `チー 234s`（順子）
  - `ミンカン 1111s`（明槓）
  - `アンカン 中中中中`（暗槓）
- 和了牌: `ツモ 6m` / `ロン 9s`。

### ルールの約束事（デフォルト）
- **ドラ**: `ドラ ○` は**実際のドラ牌そのもの**を指す（表示牌ではない）。
  符計算の練習に集中させるため、**原則として手牌に存在しない牌をドラに選び、ドラ0にする**。
  ドラを絡めて点数まで問いたいときだけ、手牌にある牌をドラにする。
- **場風**: 明示がなければ **東場**。南場を想定するときは問題文に「南場」を添える。
- **自風**: `○家` で示す（東家＝親、それ以外＝子）。
  雀頭・刻子が役牌かどうかは「場風／自風／三元牌」で判定する（連風牌の雀頭は
  [[fu-calculation]] のルール差に従い、デフォルト2符）。

## 問題を作る手順

1. **狙う論点を決める**（何を練習させたいか）。代表的な符の要素:
   - 待ち: 両面/双碰=0符、嵌張/辺張/単騎/ノベタン=2符
   - 刻子・槓子: 明/暗 × 刻/槓 × 中張/么九（[[fu-calculation]] の表）
   - 雀頭: 役牌2符 / それ以外0符（西西など「自風でも場風でもない客風」は0符）
   - 和了り方: 門前ロン+10 / ツモ+2 / 鳴きロン0
   - 特例: 平和ツモ20、平和ロン30、七対子25、喰い平和形30
2. **和了形を組む**（4面子+雀頭、または七対子・国士）。牌は各4枚まで。
3. **待ちを作る**: 和了牌を1枚抜いた形がテンパイになるよう調整し、`ツモ/ロン <牌>` を決める。
   - ロンで完成した刻子は**明刻**扱いになる点を利用すると良問になる。
   - 双碰待ちのロン/ツモで刻子の明暗が変わる論点を仕込める。
4. **役を最低1つ持たせる**（役なしは和了れない＝不正な問題）。
   - 鳴き手は役牌・タンヤオ・混一・対々などで役を確保。
   - リーチ有りにするなら門前限定。鳴き手に「リーチ有り」は付けない。
5. **ドラ・場風・自風を設定**（上記デフォルト）。
6. **想定解を計算**（[[fu-calculation]]）: 符→飜→点数。
7. **検証チェック**を通す。

## 検証チェックリスト（必ず確認）

- [ ] 各牌の枚数が4枚以下（アンカン等の4枚使用と重複しないか）。
- [ ] 手牌＋鳴き＋和了牌の合計が14枚（槓ごとに+1枚）。
- [ ] 和了牌を除いた形が正しくテンパイしている。
- [ ] **役が最低1つある**（ドラは役ではない）。
- [ ] 門前を要する役（リーチ/平和/一盃口/門前ツモ等）を鳴き手に付けていない。
- [ ] 待ち・刻子の明暗が和了牌（ツモ/ロン）と整合している。
- [ ] 符の合計を1の位で切り上げ済み（特例の20/25は切り上げない）。

## 難易度の目安

- **易**: 門前・両面・役牌なし雀頭など、加符が少なく30〜40符に落ち着く形。
- **中**: 暗刻・嵌張・役牌雀頭・双碰の明暗などを1〜2個組み合わせる。
- **難**: 暗槓（么九32符）、複数の么九暗刻、喰い平和形、平和ツモ/七対子の特例、
  高点法で待ちの取り方が複数ある形。

## 出題の出し方

- 依頼された問数だけ作る（指定がなければ1問）。難易度・論点の指定があれば従う。
- **問題文と解答は分けて提示**する（解答は「▼解答」等で畳む書き方でもよい）。
- 解答は**符の内訳を明示**し、飜・点数まで示す:

```
▼解答
符: 基本20 + <各要素> = <合計> → <切り上げ>符
飜: <役と飜> = <合計>飜（ドラ<数>）
点数: <子/親>・<ロン/ツモ> <点数>
```

## 作例（想定解つき）

すべて `ドラ 4p` は手牌に無い牌＝**ドラ0**、場風は**東場**。

### 例1（40符2飜）
```
ドラ 4p 東家 リーチ有り
23445m555p999s中中
ツモ 6m
```
▼解答: 234m/456m/555p/999s/中中、45m両面で6mツモ。
符 = 20 + ツモ2 + 555p暗刻4 + 999s暗刻8 + 中中雀頭(三元牌)2 + 両面0 = 36 → **40符**。
飜 = リーチ1 + 門前ツモ1 = **2飜**（ドラ0）。
点数 = 子ツモ **700/1300**（40符2飜、合計2700）。

### 例2（40符1飜）
```
ドラ 4p 南家 リーチ無し
23445m555999s中中
ツモ 6m
```
▼解答: 234m/456m/555s/999s/中中、45m両面で6mツモ。
符 = 20 + ツモ2 + 555s暗刻4 + 999s暗刻8 + 中中雀頭2 + 両面0 = 36 → **40符**。
飜 = 門前ツモ1 = **1飜**。
点数 = 子ツモ **400/700**（40符1飜、合計1500）。

### 例3（30符3飜・平和）
```
ドラ 4p 南家 リーチ有り
23445m556677p西西
ロン 6m
```
▼解答: 234m/456m/567p/567p/西西、45m両面で6mロン。
西は東場・南家では役牌でない→雀頭0符。全順子・両面・非役牌雀頭で**平和**。
符 = 20 + 門前ロン10 = **30符**。
飜 = リーチ1 + 平和1 + 一盃口1（567p×2）= **3飜**（西があるのでタンヤオ不成立）。
点数 = 子ロン **3900**（30符3飜）。

### 例4（40符1飜・鳴き）
```
ドラ 4p 南家 リーチ無し
555m1199s ポン 中中中 チー 234s
ロン 9s
```
▼解答: 555m暗刻 / 中中中明刻 / 234s / 1199s、双碰で9sロン→999s明刻・11s雀頭。
符 = 20 + 555m暗刻4 + 中中中明刻(字牌)4 + 999s明刻(老頭)4 + 11s雀頭0 + 双碰0 + 鳴きロン0 = 32 → **40符**。
飜 = 中（役牌）1 = **1飜**。
点数 = 子ロン **1300**（40符1飜）。

### 例5（70符1飜・暗槓）
```
ドラ 4p 南家 リーチ無し
555m1199s アンカン 中中中中 チー 234s
ツモ 1s
```
▼解答: 555m暗刻 / 中中中中暗槓 / 234s / 1199s、双碰で1sツモ→111s暗刻・99s雀頭。
符 = 20 + 555m暗刻4 + 中中中中暗槓(字牌)32 + 111s暗刻(老頭)8 + 99s雀頭0 + 双碰0 + ツモ2 = 66 → **70符**。
飜 = 中（役牌）1 = **1飜**（鳴きありなので門前ツモは付かない）。
点数 = 子ツモ **600/1200**（70符1飜、合計2400）。
