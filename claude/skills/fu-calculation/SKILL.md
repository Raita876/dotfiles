# 麻雀 符計算・点数計算スキル

和了り手から**符 → 実際の点数**までを求める手順とルールをまとめる。
まず符を算出し（前半）、次に符と飜数から点数を算出する（後半「点数計算」章）。

## 計算式（全体）

```
符 = 基本符(副底) + Σ面子の符 + 雀頭の符 + 待ちの符 + 和了り方の符
    → 最後に 1の位を切り上げ（10単位に繰り上げ）
```

**先に特例（下記「特例」章）を必ずチェックする。** 特例に該当したら固定符を使い、
通常の加算はしない（平和ツモ=20、七対子=25 は切り上げもしない）。

## 1. 基本符（副底）＝ 20符

どんな和了りでも必ず20符。ここに以下を足していく。

## 2. 面子の符

順子は常に0符。刻子・槓子は「牌の種類」×「明/暗・刻/槓」で決まる。
**么九牌（1・9の数牌 と 字牌）は中張牌（2〜8の数牌）の2倍。**

| 面子 | 中張牌(2〜8) | 么九牌(1・9・字牌) |
|------|:---:|:---:|
| 順子 | 0 | 0 |
| 明刻（ポン、またはロンで完成した刻子） | 2 | 4 |
| 暗刻（手の内で完成／ツモで完成） | 4 | 8 |
| 明槓 | 8 | 16 |
| 暗槓 | 16 | 32 |

判定の注意:
- **ロンで完成した刻子は「明刻」扱い**（自分の手の内だけで揃っていないため）。
  ツモで3枚目を引いた刻子は暗刻。もともと手の内に3枚あればロン和了でも暗刻。
- 槓子は必ず刻子より符が高い。暗槓32符（么九）が単一面子の最大。

## 3. 雀頭の符

| 雀頭 | 符 |
|------|:---:|
| 役牌（自風牌・場風牌・三元牌） | 2 |
| それ以外（数牌・オタ風＝客風牌） | 0 |

- **連風牌（ダブ東・ダブ南など、自風かつ場風の牌）の雀頭**は
  **2符（一般・フリー雀荘で主流）／4符（競技・プロ団体で多い）** のルール差がある。
  取り決めが不明なら**2符をデフォルト**とし、4符ルールの可能性を一言添える。

## 4. 待ちの符

「和了り牌が待ちのどの形にはまったか」で判定する。同じ手でも解釈が複数あるときは
**符が高くなる待ちを採用してよい**（高点法）。

| 待ち | 符 | 説明 |
|------|:---:|------|
| 両面（リャンメン） | 0 | 例 34 で 2-5 待ち |
| 双碰（シャンポン） | 0 | 対子2つのどちらかが刻子になる待ち |
| 嵌張（カンチャン） | 2 | 例 1_3 の 2 待ち（間の1つ） |
| 辺張（ペンチャン） | 2 | 12 で 3 待ち／89 で 7 待ち（端の片面） |
| 単騎（タンキ） | 2 | 雀頭の片割れ待ち |
| ノベタン | 2 | 例 2345 の 2・5 待ち（単騎扱い） |

## 5. 和了り方の符

| 和了り方 | 符 |
|------|:---:|
| 門前ロン（メンゼンロン加符） | +10 |
| ツモ（門前・鳴き問わず） | +2 |
| 鳴きロン | 0 |

## 特例（最優先で判定）

1. **平和ツモ ＝ 一律20符（切り上げなし）**
   平和成立にはツモ2符・待ち2符・雀頭符などが全て0である必要がある。
   ツモの+2符を付けると平和が崩れるため、平和ツモは加符せず20符固定。
2. **平和ロン ＝ 30符**
   20符（基本）＋10符（門前ロン）。加符要素は他になし。
3. **七対子 ＝ 一律25符（切り上げなし）**
   面子・待ちの符は考えない。門前限定なので必ず25符。
4. **喰い平和形（鳴きで加符が一切なく合計20符のロン）＝ 30符に繰り上げ**
   鳴きロンで面子0・雀頭0・待ち0だと20符になるが、20符ロンは存在しないため
   30符として扱う（ツモなら+2で22符→切り上げ30符）。

## 6. 切り上げ

特例（平和ツモ20・七対子25）を除き、合計の**1の位をすべて切り上げる**。
例: 32符 → 40符、22符 → 30符、40符 → 40符（そのまま）。

## 実戦での典型値（暗記の助け）

門前手はロンで加符10がつくため、多くが30符・40符に落ち着く。
- 門前ロン・特に符がつかない形 → **30符**
- ツモ全般（平和以外）→ ほぼ **30符以上**（副底20＋ツモ2＝22→30が下限）
- 鳴き手のロンで加符が少ない → **20符** になり得る（喰い平和形のみ例外で30符）

## 計算手順（このスキルの使い方）

1. **特例判定**: 平和ツモ／平和ロン／七対子／喰い平和形か。該当なら固定符を出して終了。
2. 基本符 20 を置く。
3. 面子ごとに符を加算（中張/么九、明/暗、刻/槓、ロン完成刻子=明刻に注意）。
4. 雀頭の符を加算（役牌2、連風牌はルール確認）。
5. 待ちの符を加算（高点法で有利な待ちを選ぶ）。
6. 和了り方の符を加算（門前ロン+10 / ツモ+2 / 鳴きロン0）。
7. 合計を1の位で切り上げ。
8. 結果は**内訳（各項目の符）を明示**して提示する。可能なら符から飜数と合わせて点数まで求める。

## 計算例

**例1: 門前ツモ、暗刻(西=場風でない客風の刻子)、両面待ち**
`基本20 + 暗刻(中張)4? ...` のように、まず各面子の牌種を確定してから足す。
- 手: 一二三(順)・678(順)・西西西(暗刻/客風)・南南南(暗刻)・白白(雀頭)、門前ツモ、両面待ち
  ※このケースは説明用。実際は待ち牌で解釈が変わる点に注意。

**例2: 平和・門前ロン**
順子4＋雀頭が数牌／客風＋両面待ち＋門前ロン → 特例2により **30符**。

**例3: 七対子** → **25符**（無条件）。

# 点数計算（符・飜 → 実点数）

符が出たら、飜数と合わせて実際の点数を求める。

## 基本式

```
基本点 = 符 × 2^(飜数 + 2)
```

この「基本点」を和了り者の立場（子/親）と和了り方（ロン/ツモ）で配分し、
**各支払いを100点単位で切り上げる**（合計ではなく1人ぶんごとに切り上げ）。

| | ロン（放銃者が全額） | ツモ（分割払い） |
|---|---|---|
| **子** | 基本点 × 4 | 親: 基本点×2 ／ 子: 基本点×1（他2人） |
| **親** | 基本点 × 6 | 全員: 基本点×2（3人とも同額） |

- ツモ表記「a / b」は「子の支払い / 親の支払い」（子和了り時）。親和了りツモは全員同額。
- 例: 子・30符3飜 → 基本点 960。ロン 960×4=3840→**3900**。
  ツモ 子払い960→1000・親払い1920→2000 → **1000/2000**。

## 満貫の上限（頭打ち）

基本点が **2000を超えたら満貫**として基本点を2000で頭打ちにする。
実際には次の符・飜で満貫になる（それ以上の細かい符計算は不要）:
- **4飜40符以上**、**3飜70符以上**（基本点2000超）→ 満貫。
- 5飜は符に関係なく満貫。

| 跳満 | 6〜7飜 | 3000 | 12000 | 3000/6000 | 18000 | 6000 |

## 点数計算の手順（このスキルの使い方）

1. 前半の手順で**符を確定**する。
2. **飜数を数える**（役＋ドラ。ドラは飜だが符には影響しない）。
3. 満貫以上（5飜↑、または4飜40符↑・3飜70符↑）なら満貫以上の表を使う。
4. それ未満なら `基本点 = 符 × 2^(飜+2)` から配分し、各支払いを100点切り上げ。
   早見表で照合してもよい。
5. 結果は**「◯符◯飜 = 子/親・ロン/ツモの点数」**を内訳とともに提示する。

## ローカルルール（適用は取り決め次第）

- **切り上げ満貫**: 4飜30符（子7700/親11600）・3飜60符 を満貫扱いにするルール。
  採用卓では 8000/12000 になる。デフォルトは通常計算（7700等）とし、必要なら確認する。
- **連風牌の雀頭 4符**（前半参照）も符が変わり点数に波及する。

# 役一覧（飜数・食い下がり）

点数計算の「飜数」を数えるための役の表。**飜は「門前 / 鳴き」で示す**。
「食い下がり」は鳴くと飜が下がる役。ドラ（ドラ・赤ドラ・裏ドラ・槓ドラ）は
役ではないが飜として加算する（ドラのみでは和了れない）。
