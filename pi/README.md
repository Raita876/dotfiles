# Pi の拡張

## Herdr Space の自動命名

`extensions/herdr-auto-name/` は、Herdr 内の Pi の会話から短い Space 名を生成するローカル拡張。Home Manager の `programs.pi-coding-agent.settings.extensions` から読み込む。

通常の `~/Repository/dotfiles` に変更を取り込み、Pi を終了して `nix run .#switch` を実行し、Pi を起動し直す。拡張のコード自体はリポジトリから直接読み込むため、以後のコード変更は Pi の再起動または `/reload` で反映できる。

### 動作

- Herdr 内で動くローカルの対話型 Pi のみが対象。Herdr 外、RPC・非対話モード、子ターミナルでは動かない。
- 応答が正常に完了し、Pi が待機状態になったときにバックグラウンドで生成する。各 Space の選択中のタブで、最初の Pi ターミナルだけが命名する。
- 直近 6 件のユーザー・アシスタントの本文を各 2,000 文字まで、現在のモデルへ追加で送る。ツール結果・思考・画像は送らず、生成側にツールも渡さない。**追加の API 利用と料金が発生する**。本文に含まれる機密情報まで自動で除去するものではない。
- 生成は最短 60 秒間隔。同じ会話では再生成せず、30 秒で打ち切る。次の入力やセッション終了でも中止する。
- Herdr の端末ラベルから Space ID を取得して明示的に指定する。未命名、または同じ端末が前回付けた名前のままの Space だけを更新する。前回の名前・会話のハッシュ・更新時刻は端末ラベルに保持し、会話本文は保存しない。
- 手動で別の名前を付けると停止する。名前を空に戻すと再開する。接続や生成に失敗した場合はスキップし、Pi に一度だけ警告を表示する。

Herdr に条件付き rename API がないため、最後の状態確認と rename の間の手動変更は完全には保護できない。また、自動名と同じ文字列を手動で設定した場合は判別できない。別の端末で Pi を起動し直すと既存の自動名も手動名として扱うので、必要なら名前を空に戻す。

### 無効化

起動時に環境変数を指定する。機密情報を扱う場合も、この方法で追加のモデル呼び出しを止められる。

```sh
PI_HERDR_AUTO_NAME=0 pi
```

常に無効にする場合は `~/.zshrc.local` に `export PI_HERDR_AUTO_NAME=0` を設定する。Oh My Pi (`omp`) にはこの拡張を読み込まない。

### テスト

```sh
node --test pi/extensions/herdr-auto-name/naming.test.mjs
```

生成処理はスタブ、Herdr の通信は一時 Unix ソケットで検証する。実際の Space やモデル API は変更・呼び出ししない。
